# Eficaz Engine

Plataforma de gestão de clientes, auditorias de sites e prospecção de leads.

## Funcionalidades

- Auditoria de sites: análise, descoberta de páginas, listagem, atualização de status e auditoria individual.
- Prospecção de leads: listagem, filtros, importação, exportação, enriquecimento e relatórios.
- Gestão de clientes com rotas e interfaces segmentadas por `client_slug`.
- Controle de acesso e áreas administrativas.

## Estrutura

A aplicação Next.js está dentro deste diretório (`src`), que deve ser configurado como o **Root Directory** no Vercel.

## Deploy

No Vercel, configure **Settings → General → Root Directory** como `src` e faça um novo deploy.

## Desenvolvimento

O projeto utiliza Next.js, React, TypeScript, Tailwind CSS e Supabase.
